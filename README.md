## 💻 Local Development

1. **Clone repository:**
   ```bash
   git clone https://github.com/aldanmar/aldanmar-site.git
   cd aldanmar-site
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```
