## 🚀 Live Demo
- **GitHub Pages:** [https://knetaus.github.io/aldanmar-site/](https://knetaus.github.io/aldanmar-site/)

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Animation:** Motion
- **Icons:** Lucide React

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/knetaus/aldanmar-site.git
   cd aldanmar-site
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
